Bundled fonts (used when the Windows font of the same look is not installed)
  Tinos            -> looks and measures like Times New Roman   (Apache 2.0)
  Carlito          -> looks and measures like Calibri           (SIL Open Font License 1.1)
  Caladea          -> looks and measures like Cambria           (Apache 2.0 / OFL)
  Liberation Sans  -> looks and measures like Arial             (SIL Open Font License 1.1)
  Liberation Mono  -> looks and measures like Courier New       (SIL Open Font License 1.1)
Licence texts are in the "licenses" folder. If Windows has the real Times New Roman, Calibri, Arial, Cambria or Courier New, the program uses those.
